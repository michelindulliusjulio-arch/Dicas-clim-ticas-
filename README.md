# 🌿 EcoBot — Assistente de Sustentabilidade

## 📌 Sobre o projeto

O EcoBot é um programa desenvolvido em Python para conscientizar as pessoas sobre a importância de preservar o meio ambiente.

## 🎯 Objetivo

Incentivar hábitos sustentáveis e ensinar como pequenas atitudes podem ajudar o planeta.

## 🚀 Funcionalidades

- 🌱 Dicas de sustentabilidade.
- 💧 Informações para economizar água.
- ♻️ Orientações sobre reciclagem.
- 🧠 Quiz ambiental com pontuação.
- 🌍 Curiosidades sobre o meio ambiente.

## 💻 Tecnologias

- Python 3
- Estruturas condicionais (`if` e `elif`)
- Laços de repetição (`while`)
- Funções (`def`)

## ▶️ Como executar

1. Instale o Python 3.
2. Baixe o arquivo `ecobot.py`.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python ecobot.py
```

## 🌳 Importância do projeto

O EcoBot busca mostrar que pequenas mudanças nos nossos hábitos podem contribuir para a preservação da natureza.
